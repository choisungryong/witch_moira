## 0. 한 장 요약

- **뼈대**: 등장(2초) → 1국면 → **쉼 1**(10초) → 2국면 → **쉼 2·격노**(9초) → 3국면. 쉼 동안 우두머리는 자리를 옮기고 표적에서 빠지며, 호위가 몰려온다. 쉼은 정해진 틱으로 끝나고 장비·호위 처치·필살기 어느 것으로도 줄지 않는다. 이것이 "장비가 줄이지 못하는 시간"이다(RC5).
- **첫 값** [손셈]: 우두머리 체력 4,500 → **15,000**, 설계한 고정 시간 26초. 맨몸 화염 약 51초 · 냉기 약 73초 · 번개 약 79초, 장비 갖춤 화염 약 37초.
- **이 명세 혼자로는 닿지 못하는 줄이 둘 있다** [손셈, 근거 2.3절]: 계열 최대÷최소 ≤ 1.3, 냉기·번개의 장비 갖춤 35~60초. 지금 냉기·번개는 우두머리에게 넣는 주력 피해가 화염의 0.41배·0.21배이고, 기준 착용(f2v q50)에서는 장비가 이 값을 올리지 않는다 [실측 계열 20판]. 고정 시간만으로 1.3을 맞추면 화염 싸움의 74%가 쉼이 된다. 그래서 계열 차는 속성별 트리 재설계(`D-element-trees-direction-20261124`)와 장비 옵션 재설계로 넘기고, 이 명세는 **화염 줄과 모든 계열의 바닥(최소 50초)**을 맡는다.
- **새로 알게 된 것**: RC-A의 장비 갖춤 열에서 냉기·번개가 거의 줄지 않은 것은 고정 시간만이 아니라 **착용 묶음의 피해 합이 작은 탓**이 크다. q50 묶음의 `damage_bps` 합이 화염 12,442 · 냉기 5,489 · 번개 4,020이다 [본 것: VR-E 보고 5절 기록]. RC18의 읽기를 고칠 거리다(9절 C6).
- 쉼과 강림: 쉼 안에서 강림을 쓰면 호위를 쓸고(살아남기), 드러난 국면에서 쓰면 우두머리 체력 최대 18%를 깎는다(빨리 끝내기). 셋째 필살기의 "아낄까 쓸까"가 여기서 갈린다 `[도]`.

### 2.2 처치 시간의 틀 [손셈]

```
T(계열, 착용) = o + F + k × W_now(계열) ÷ m(계열, 착용)
  o      : 등장 뒤 첫 공격까지 다가가는 자연 시간. 지금 값이 없어 1.5초로 둠 [가설]
  F      : 설계한 고정 시간 26초(2.1절)
  k      : 새 체력 ÷ 4,500
  W_now  : 지금 맨몸 싸움에서 o를 뺀 일의 양 = 8.6/15.2/16.8 − 1.5 = 7.1 / 13.7 / 15.3초
  m      : 장비 배율. 지금 맨몸·장비 갖춤 두 점에서 = 7.1/2.8, 13.7/13.4, 15.3/14.2 = 2.54 / 1.02 / 1.08
```

- 화염은 o가 작고 거의 모두 일이라 장비 배율이 그대로 시간을 깎는다. 냉기·번개는 일의 양이 두 배쯤이고, 기준 착용이 일을 거의 줄이지 못한다.
- **F는 세 계열에 같다.** F가 클수록 계열 사이의 비가 1에 가까워지고 장비÷맨몸이 커진다. 대가는 싸움에서 쉼의 몫이 커지는 것이다. 이 셋을 한 표로 본다.

**안 다 (비교): 계열 비 1.3을 고정 시간으로만 맞춤** — 비의 조건 `0.3 × (o + F) ≥ W_화염 × (r − 1.3)`, r = 번개 ÷ 화염의 일 = 2.15. 화염 맨몸을 50초에 두면 W_화염 13초, o + F 37초(체력 약 8,200). 화염 싸움의 74%가 쉼이고 국면마다 일이 4초 남짓이다. **"질질 끎"이라 거둔다.**

**안 라 (속성 트리 뒤의 목표): 체력 20,000, F = 26초, 냉기·번개의 우두머리 일이 화염의 1.35배 이하, 장비 배율 2 이상** — 맨몸 59.0 / 70.1 / 70.1초, 장비 39.9 / 48.8 / 48.8초, 최대÷최소 1.19 / 1.22, 장비÷맨몸 0.68 / 0.70. **모든 줄이 안이다.** 이것이 문서 2(속성별 트리)와 장비 옵션 재설계에 넘기는 수치 목표다: **우두머리에 넣는 피해(보조 포함)가 화염의 0.74배 이상, 기준 착용이 그 피해를 2배 이상 키운다.**

읽는 법:
- 고정 시간이 0에 가까운 화염과 몇 초를 안은 냉기·번개는 같은 F 26초를 받는다. 화염은 F 덕에 장비÷맨몸이 0.41 → 0.72로 오르고(장비가 결을 지우지 못함), 냉기·번개는 F가 비를 1.53까지 끌어내린다(지금 1.96). 남은 0.23은 피해 쪽 차이라 싸움의 틀로는 줄이지 않는다.
- 맨몸 번개 78.5초는 80초 줄에 1.5초 남는다. 체력은 15,000을 넘기지 않는다. 속성 트리가 들어오는 날 안 라로 올린다(체력은 그때 다시 셈).
- 이 손셈은 o를 1.5초로 놓았고, 새 공격(돌진·폭풍)을 피하느라 줄어드는 피해 시간을 넣지 않았다. 실제 판은 일이 10~20% 길어질 것으로 본다 [가설]. 그래서 첫 값은 줄의 안쪽(화염 51초)이 아니라 확인 판 뒤 7절 ②가 맞춘다.

- **쉼이 "질질 끎"이 되지 않게** (BF4): 쉼 동안 우두머리를 칠 수는 없지만 할 일이 셋 있다 — 호위(처치가 경험치 구슬·강림 점수·사슬 깎기로 돌아옴), 착지·폭풍 피하기, 강림의 창. 쉼 하나에 맨몸 자동 조작이 호위를 10마리 이상 잡아야 한다(BF-T4).

- **필살기 셋째와 맞물림** (RC6, RC13, BF7): 지금 셋째는 우두머리 등장 33~43초 앞에 찬다 [실측 30판]. RC13의 `cost[2]` 11000이면 19~38초 앞 [모델의 답]. 우두머리 앞에서 쓰지 않고 들고 온 플레이어는 세 창 가운데 하나를 고른다.
  - 쉼 1·2에서 쓰면: 호위를 쓸고 우두머리에게는 아무것도 하지 않는다(표적에서 빠짐). 살아남는 쪽 `[도]`.
  - 1~3국면에서 쓰면: 우두머리 체력 최대 18%. 국면 문턱에서 멈추므로(BF3) 국면 초반에 써야 다 들어간다. 빨리 끝내는 쪽 `[쾌]`.
  - **강림은 쉼을 줄이지 않는다.** 고정 시간을 지키는 규칙이다. 판정 줄은 강림 꺼짐 판으로 잰다(RC-A와 같음). 강림 켬 판은 참고 열(BF-T8).

## 5. 데이터 형식과 코어가 낼 이벤트 (BF9)

### 5.1 `combat_tuning.json`의 새 선택 블록 `boss_finale` [가설]

없거나 `enabled: false`면 지금과 같다: 새 난수를 한 번도 뽑지 않고, `champions[2]`·`spawn.boss_phase`·`rhythm.boss.phase_break_ticks`를 지금대로 쓴다 → **모든 골든 해시 불변**.

```json
"boss_finale": {
  "enabled": false,
  "hp": 15000,
  "entrance_ticks": 120,
  "phases": [
    {"id": "p1", "to_hp_bps": 6500, "recover": 90,
     "ward": {"every_ticks": 240, "centers": 1},
     "adds": {"amount": 2, "interval_ticks": 60, "alive_cap": 10},
     "slam": null},
    {"id": "p2", "to_hp_bps": 3000, "recover": 65,
     "ward": {"every_ticks": 180, "centers": 3},
     "adds": {"amount": 2, "interval_ticks": 60, "alive_cap": 10},
     "slam": {"every_attacks": 3, "windup_ticks": 72, "length_m": 10.0, "width_m": 2.0, "damage": 70}},
    {"id": "p3", "to_hp_bps": 0, "recover": 55,
     "ward": {"every_ticks": 150, "centers": 3},
     "adds": null,
     "slam": {"every_attacks": 2, "windup_ticks": 72, "length_m": 10.0, "width_m": 2.0, "damage": 70}}
  ],
  "breaks": [
    {"after": "p1", "ticks": 600, "relocate_m": [9.0, 12.0],
     "land": {"windup_ticks": 72, "radius_m": 3.0, "damage": 55},
     "escort": {"first": 16, "amount": 3, "interval_ticks": 60, "alive_cap": 28, "mix": {"walker": 70, "charger": 30}},
     "storm": null, "potion_drops": 0, "chip_bps_per_kill": 25, "chip_cap_bps": 500},
    {"after": "p2", "ticks": 540, "relocate_m": [9.0, 12.0],
     "land": {"windup_ticks": 72, "radius_m": 3.0, "damage": 55},
     "escort": {"first": 16, "amount": 3, "interval_ticks": 60, "alive_cap": 28, "mix": {"walker": 70, "charger": 30}},
     "storm": {"every_ticks": 90, "centers": 5, "ring_m": [1.5, 4.5], "radius_m": 1.8, "windup_ticks": 60, "damage": 40},
     "potion_drops": 1, "chip_bps_per_kill": 25, "chip_cap_bps": 500}
  ]
}
```

규칙:
1. `hp`가 `champions[2].hp`를 덮는다(켠 판만). 다른 값(공격력·전조)은 `champions[2]`를 그대로 쓴다.
2. 체력이 `to_hp_bps` 아래로 내려가면 그 값에서 멈추고(넘친 피해 버림) 다음 쉼으로 간다. `p3`의 0은 처치다.
3. 쉼 동안 우두머리는 표적에서 빠진다(자동 겨눔·연쇄·관통이 고르지 않음)와 무적. 몸 공격·바닥 공격을 멈춘다. 쉼의 `ticks`가 지나면 `relocate_m` 거리의 자리(주인공 기준, 경기장 안으로 자름)에 착지 전조를 내고, 전조가 끝나면 다음 국면이 시작된다. 쉼의 길이는 어떤 것에도 줄지 않는다(장비·처치·강림).
4. 자리와 폭풍 자리는 주인공 위치·방향만으로 정한다(지금 바닥 공격과 같은 방식). 호위의 생성 자리·종류만 지금의 생성 난수(`_spawn_rng`)를 쓴다 — 켠 판만.
5. 켠 판에서는 `spawn.boss_phase`를 쓰지 않고 국면의 `adds`를 쓴다(`null`이면 생성 없음). 기존 2국면 전환(50%)과 `phase_break_ticks`도 쓰지 않는다.
6. 사슬 깎기: 쉼 안에서 죽은 호위 하나마다 다음 국면의 시작 체력을 `chip_bps_per_kill`만큼(최대 생명 기준) 깎되 쉼 하나에 `chip_cap_bps`까지. 0이면 끔.
7. 검증(`combat_tuning.gd`): 국면 `to_hp_bps`는 엄격히 줄고 마지막은 0, `breaks[].after`는 마지막이 아닌 국면 id, 최대 생명 20% 이상 피해(주인공 기본 120 기준 24 이상)를 주는 모든 공격의 전조 ≥ 54틱.
8. 상태는 스냅숏에 `boss_finale {phase_index, break_index, break_until, chip_bps}` 한 키로(켠 판만).

## 7. 배정문 초안

### ① gameplay-systems — 코어 (꺼진 스위치)

- 5.1절의 블록과 규칙 1~8, 5.2절의 이벤트. `combat_tuning.gd` 검증(선택 키, 규칙 7).
