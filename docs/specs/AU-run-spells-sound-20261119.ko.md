- 작성: audio-lead, 2026-11-19. 읽기와 문서 작성만 했다. **Godot·합성·생성·측정은 하나도 돌리지 않았다.** 소리 재료를 다른 AI 모델이나 외부 서비스에 넘기지 않았다.
- 받는 장부 줄: `docs/DIRECTIVES-LEDGER.ko.md` 2절 `run_spells.json enabled`의 남은 일 **⑤ 소리**.
- 받는 목록: `docs/specs/A6-run-spells-screen-20261119.ko.md` RS5(10줄)와 1.2절(이벤트 표).
- 기준: `docs/AUDIO-PLAN.ko.md`, `docs/specs/S1-audio-direction.ko.md` 2판(3.1 층, 3.2 계열, 3.4 군중 묶음, 6.2 음량, 6.3 우선), `docs/specs/D12-skill-and-gear-redesign.ko.md` B0.13 3.1(원형 = 근접 차단, 0.5~0.9초마다), B0.14(I0·I1·I2).
- 표기: **[코드]** 이 저장소의 파일을 읽어 확인 / **[모형]** 코드의 수를 셈해 미루어 본 값 / **[가설]** 내 판단, 측정·청취로 확인할 것 / **[미확인]** 확인하지 못함. 소리가 "좋다·어울린다·피곤하지 않다"는 판정은 이 문서에 없다. 그것은 사용자의 청취로만 채운다(지금 모두 **미평가**).

**소리를 내지 않는 이벤트**: `cast.prefer:"kind"`(I0), `stagger`(끊음 아님), `stun`(번개 원형), 냉기 원형의 `hit.frozen`, 원형의 `hit`(일반 명중 소리로 보내지 않음). 마지막 넷은 따로 울리지 않고 **원형 맥박 한 번에 접혀 들어간다**. 까닭은 3절.

**섹시**는 이 문서의 어느 묶음도 키우지 않는다. 후원자·마녀의 목소리 반응(큰 맞물림 뒤 짧은 기합)은 목소리 결정 A-3(제1장은 기합·피격만)과 A6-16(인물) 뒤로 미룬다.

**꺼진 경로 불변이 모든 묶음의 첫 통과 조건이다.** `enabled:false`에서 소리 요청 기록(`report_audio_requests.gd`의 `requests` 배열)이 바이트 단위로 같고, `golden_core.gd`가 바뀌지 않는다(표현만 고치므로).

### 1.4 지금 켜면 생기는 일 [코드 + 모형]

1. **냉기·번개 원형이 화염 시전 소리를 낸다.** 230행의 기본값이 `"fire"`다.
2. **번개 마녀에게는 더 나쁘다.** 번개 기본기는 `SILENT`라 조용한데, 번개 원형은 `"fire"`라 무음 목록에 걸리지 않는다. 사용자가 거슬린다고 끈 자리에 0.5~0.9초마다 화염 시전 소리가 대신 들어간다.
3. **화염 원형과 화염 기본기가 쿨 하나를 나눠 쓴다.** 둘 다 `"fire"`이고 쿨은 10틱이라, 둘이 10틱 안에 겹치면 뒤의 것이 버려진다.
4. **원형의 명중이 일반 명중의 쿨을 먹는다.** 원형 명중이 `impact`(쿨 7틱)를 쓰면 그 뒤 7틱 안의 기본기 명중이 버려진다. 원형이 0.5초마다 돌면 시간의 약 23%(7/30)가 그렇다 [모형].
5. **시전 꼴의 소리가 두 배 가까이 된다.** 기본기 60~75번/분에 원형 67~120번/분이 더해진다(쿨과 발동 조건에서) [모형]. S1 3.4의 "시전 계열마다 초당 6"은 넘지 않지만, 귀에 닿는 반복 리듬이 하나 더 생긴다.

## 2. 원칙 — 이 문서에서 정한 것

1. **원형 한 번 = 소리 한 묶음.** 원형의 `cast`와 같은 틱에 그 원형이 낸 `hit`·`stagger`(끊음 아님)·`stun`·빙결은 따로 울리지 않고 **맥박 한 번**으로 접는다. 같은 틱의 이벤트가 이미 다 와 있으므로(1.2) 늦출 것이 없다. S1 3.4 "같은 틱은 한 번"을 원형에 적용한 것이다.
2. **잦은 것은 작게, 드문 것은 크게.** 크기 차례: 원형 맥박(가장 잦음, 가장 작음) < I1 덧소리 < I2 터뜨림 ≈ 끊음(드묾, 또렷함). 맞물림이 "보상"으로 들리려면 바탕(맥박)이 낮아야 한다.
3. **원소는 꼬리로 가른다.** 한 판에 원형은 하나라(1.3) 원형끼리 갈릴 일은 없다. 몸통은 셋이 같이 쓰고, 꼬리만 그 마녀의 기본기와 같은 계열로 둔다(S1 3.2의 꼬리 대역).
4. **번개 쪽은 사용자 결정을 따른다.** 번개 계열의 꼬리는 "전류가 흐르는 소리"(U-21)의 후보(L1~L4) 가운데 사용자가 고른 것과 같은 결로 만든다. 고르기 전에는 번개 꼬리를 **무음**으로 두고 몸통만 낸다.
5. **소리 때문에 코어를 바꾸지 않는다.** 이 문서의 모든 판정은 이미 있는 이벤트 필드와 같은 틱의 묶음에서 한다. 코어 파일·데이터 파일(`run_spells.json` 포함)은 건드리지 않고 `enabled`를 켜지 않는다.
6. **결정론**: 음높이 흔들기·변주 고르기는 코어 난수를 쓰지 않는다. 오프라인 믹서가 게임과 같은 결과를 내야 하므로(1.1), 무작위 대신 **정해진 표를 차례로 돈다**(3.1).

## 3. 이벤트마다의 판정 (RS5 10줄 + 숨은 1줄)

음량은 S1 6.2의 재는 법(Master 출력, 400ms 창 최대 = M최대)이다. 기준점은 **주력 시전 −28~−25**와 **명중 1마리 −27~−24**. 지금 옛 소리에서는 `audio_measure.py`의 "게임 안" 열(`M최대 + 20log10(.8×.11×GAINS)`)로 같은 비교를 한다.

### 3.1 `cast` + `shape:"ring"` — **낸다: 원형 맥박** [키움: 쾌감, 성장]

| 항목 | 값 |
|---|---|
| 성격 한 줄 | 짧고 둔한 "퉁" — 주인공 둘레로 한 번 밀어내는 압력. 날 선 어택이나 높은 쇳소리 없음 [가설] |
| 층 | 몸통(공용, 늘) + 원소 꼬리(조건부, 아래) = 목소리 많아야 2개 |
| 몸통 길이 | 90~160ms, 감쇠 30dB까지 ≤ 140ms |
| 몸통 어택 | 첫 표본 → 가장 큰 표본 ≤ 5ms, 앞 무음 ≤ 1ms |
| 몸통 대역 | 스펙트럼 중심 200~450Hz. 120Hz 아래 ≤ 25%(명중의 무게 층 40~150Hz를 비켜 감), 2kHz 위 ≤ 10%(적 예고·Alert 2~4kHz와 시전 꼬리를 비켜 감) |
| 원소 꼬리 | 몸통 시작 10~30ms 뒤, 몸통보다 **−6dB**, 80~200ms. 화염: 1~5kHz 타닥 낱알 2~4개 / 냉기: 3~8kHz 정수배 아닌 배음 2~3개 / 번개: 2.의 원칙 4(전류 결, 6kHz 위 ≤ 10%). 대역은 S1 3.2 D층 |
| 꼬리를 내는 조건 | 같은 틱에 그 원형이 **일반 적 하나 이상을 제어**했을 때: 화염 `stagger`(어떤 것이든) / 냉기 `hit.skill_id==frost_ring && frozen && !elite` / 번개 `stun.skill_id==arc_ring && !elite`. 강한 적만 맞은 맥박은 몸통만 [코드상 거의 늘 참 — 1.3. 그래서 사실상 "원소 정체" 층이다] |
| 음량 | M최대 **−34~−31** = 주력 시전보다 **6dB 작게**(±1). 옛 소리 단계에서는 "게임 안" 값이 같은 마녀의 기본기 시전 "게임 안" 값 −6dB ±1 |
| 맞힌 수에 따른 무게 | `cast.targets`의 수 n이 두 배가 될 때마다 +1dB, 최대 +3dB(n ≥ 8). 음높이는 수로 바꾸지 않는다(S1 3.4) |
| 쿨(이름마다) | **20틱**. 원형의 가장 짧은 쿨 30틱보다 짧아 정상 시전은 버려지지 않는다. 기본기 시전과 **쿨을 나누지 않는다**(새 소리 이름, 1.4의 3) |
| 변주 | 몸통 **4**, 꼬리 원소마다 **3**. 바로 앞 것은 다시 고르지 않는 차례 |
| 음높이 | 변주 번호와 떼어 낸 5단 표 `[.97, .985, 1.0, 1.015, 1.03]`을 차례로 돈다. 변주 4 × 음높이 5 → 같은 조합이 **20번에 한 번**(0.5초 쿨에서 10초, 0.9초에서 18초) [모형] |
| 우선 | 6(폭발·파쇄와 같은 줄). 주력 시전(5)보다 아래 |
| 원형 명중 | 그 원형의 `hit`는 `impact`로 보내지 않는다. 맥박이 명중을 대신한다(1.4의 4를 막음). 처치(`death`)는 지금처럼 공용 `death`로 |

**귀를 지치게 하지 않는 방법** — 코드의 재생 규칙에 근거해 고른 것과 버린 것:

| 방법 | 판정 | 근거 |
|---|---|---|
| 맞은 적이 있을 때만 | **이미 그렇다**, 따로 할 일 없음 | 빈 시전이 없다(1.3) |
| 원형 한 번에 소리 한 묶음(명중·제어를 접음) | **채택** | 같은 틱 묶음이 표현에 한꺼번에 닿는다(1.2). 이것만으로 원형 한 번의 요청이 `cast 1 + hit n + stagger/stun n`에서 1~2로 준다 |
| 기본기와 쿨을 나누지 않기 | **채택** | 지금은 `fire` 쿨 10틱을 나눠 서로 버린다(1.4의 3) |
| 변주와 음높이를 떼어 20번 주기로 | **채택** | 지금은 음높이가 변주 번호에 묶여 주기가 짧다(1.1) |
| **잦아지면 스스로 작아짐**(익숙해짐 감쇠) | **채택, 값은 사용자 청취로 확정** | 원형은 붙는 적이 있는 동안 쉬지 않고 돈다. 규칙: 앞선 맥박이 1.2초 안에 있었고 그 맥박에 처치·끊음·터뜨림이 없었으면 −1.5dB씩 쌓아 최대 −4.5dB. 처치·끊음·터뜨림이 있었거나 1.5초 쉬면 0dB로 돌아감. 의미 있는 맥박만 원래 크기로 남는다 [가설] |
| 매번 내지 않기(두 번에 한 번) | **기본안에서 버림, 사용자 선택지로 남김(U-2)** | 원형의 뜻이 "붙으면 맞는다"인데 소리가 빠지면 그 박자가 끊긴다. 화면의 맥박(RS1)과 어긋나 보인다 [가설] |
| 무작위 음높이 ±3% | **버림** | 오프라인 믹서와 요청 기록이 게임과 같은 결과를 내야 한다(1.1). 정해진 표로 같은 효과를 낸다 |

### 3.2 `stagger` + `cut:true` — **낸다: "막았다"** [키움: 쾌감, 보상]

| 항목 | 값 |
|---|---|
| 성격 한 줄 | 적이 휘두르려던 것이 꺾여 끊기는 소리. 막대·쇠가 맞부딪혀 멎는 짧은 "탁" + 아래로 꺾이는 몸통 [가설] |
| 길이 | 150~250ms |
| 어택 | ≤ 2ms |
| 대역 | 어택 1~4kHz, 몸통 300Hz~1.2kHz. 몸통 음높이가 첫 120ms에 3~5반음 내려감(꺾임). 주인공 피격(400Hz~2kHz 살·천, 음 없음)과 갈리게 **몸통에 울림(음) 성분**을 둔다 — 스펙트럼 평탄도가 피격 소리보다 낮을 것 |
| 음량 | M최대 **−24~−21**(명중보다 3dB 위, 큰 한 방 −21~−18 바로 아래) |
| 묶음 | 같은 틱에 끊음이 여럿이면 한 번, n ≥ 2면 +2dB |
| 쿨 | 12틱. 원소로 가르지 않는다(화염 원형만 낸다, 1.3) |
| 변주 | 4 |
| 우선 | 4(큰 한 방·정예 처치와 같은 줄) |
| 덧붙임 | 같은 틱의 원형 맥박은 그대로 낸다(끊음이 맥박의 익숙해짐 감쇠를 0으로 되돌린다, 3.1) |
| 나중 | 적 예고 소리(S1 배치표의 일반 예고)가 들어오면, 끊긴 적의 예고 소리를 20ms에 끊는다. "막았다"가 가장 또렷해지는 자리다. 지금은 예고 소리가 없다 |

RS5가 "가장 또렷해야 할 새 소리"라 한 것과 같다. 원형 쪽 소리 가운데 사람이 "내가 막았다"를 아는 유일한 신호라 맥박과 다른 결이어야 한다.

### 3.3 `stagger`(cut 아님) — **내지 않는다**

원형 맥박의 화염 꼬리로 접힌다(3.1). 따로 내면 맥박마다 일반 적 수만큼 요청이 생기고, 화면의 흔들림 표시가 이미 같은 정보를 준다.

### 3.4 `stun` + `skill_id == arc_ring` — **따로 내지 않는다**

맥박의 번개 꼬리로 접힌다(3.1). RS5의 "한 맥박에 한 번만"은 꼬리 조건으로 채워진다. 번개 기본기의 `stun`(꺼진 판에도 남)은 지금처럼 소리 없음.

### 3.5 `hit` + `skill_id == frost_ring` + `frozen` — **따로 내지 않는다**

맥박의 냉기 꼬리로 접힌다(3.1). 냉기 원형에 맞은 일반 적은 거의 늘 `frozen:true`라(1.3) 따로 울리면 맥박마다 "얼음" 소리가 하나 더 붙을 뿐이다. 얼린 적을 깨뜨리는 일(`shatter`)은 지금 규칙 그대로.

### 3.6 `detonate`(I2 터뜨림) — **낸다: 원소별** [키움: 보상, 쾌감, 도박(작게)]

| 항목 | 값 |
|---|---|
| 성격 한 줄 | 기본기가 남긴 표시가 원형에 걸려 한꺼번에 튀는 소리. 화염 `heat`: 안에서 터져 퍼지는 "팍" + 타닥 꼬리 / 냉기 `chill`: 결정이 갈라지는 "쩍" / 번개 `shock`: 고인 전류가 한 번에 빠지는 "지익"(전류 결, 원칙 4) [가설] |
| 층 | S1 3.1의 A+B+D. C(무게)는 −9dB로 얇게 — 터뜨림은 처치가 아니라 "조합" 신호 |
| 길이 | 200~350ms |
| 어택 | ≤ 3ms |
| 대역 | 150Hz 아래 15~30%, 1kHz 위 ≥ 30%. 원소 꼬리는 S1 3.2 D층 대역. 세 계열의 스펙트럼 중심이 서로 1옥타브 이상 떨어질 것 |

| 쿨 | `status`마다 15틱(초당 4 이하, S1 3.4의 폭발·파쇄와 같음) |
| 변주 | 원소마다 3(+ 긴 변주 1~2) |
| 우선 | 4 |
| 맥박과의 관계 | 같은 틱의 맥박은 그대로 내되 익숙해짐 감쇠가 0으로 돌아간다(3.1). 터뜨린 적의 `hit`는 이미 맥박에 접혀 있어 `impact`가 따로 나지 않는다 |
| 나누는 키 | `detonate.status`(heat·chill·shock). `pair` 값으로는 가르지 않는다 — 지금 터뜨림 짝은 `pair.<el>.basic_ring` 셋뿐이라 status와 1:1 [코드] |

### 3.7 `hit` + `vs_cc`(I1) — **낸다: frozen·stunned·staggered만, slowed는 내지 않음** [키움: 보상, 쾌감, 성장]

| 우선 | 5 |

### 3.8 `cast` + `prefer:"kind"`(I0) — **내지 않는다**

겨눔이 바뀐 것은 기본기 시전 소리 자체로 충분하다. I0은 가장 잦은 이벤트(기본기 시전)에 붙고, 화면의 표시도 "작게"(V-9)다. 소리를 더하면 시전 리듬이 둘로 갈려 들린다 [가설]. 사람 플레이 질문 12(D12 3.1 "멀리 있는 원거리 적을 먼저 치는 것을 알아봤나")의 답이 "몰랐다"로 오면 다시 본다.

### 3.9 `hero_hit` + `source_kind` — **이 문서에서 다루지 않음(S1 SD2로)**

방향만 적는다: 탄(`ranged`)은 날카로운 찔림(어택 2~5kHz 10~20ms, 몸통 짧게), 몸(그 밖)은 둔한 부딪힘(몸통 200Hz~1kHz 80~150ms). 두 갈래가 쿨 18틱 하나를 같이 써서 피격 소리의 총수는 늘지 않게. 다루지 않는 까닭: `source_kind`는 **꺼진 판에도 늘 실린다**(A6-RS 1.2). 지금 고치면 꺼진 판의 소리가 바뀌고, 지금 `hurt_0.wav`는 사용자가 쓸 수 없다고 한 옛 소리라 갈래를 나눌 재료가 없다. run_spells를 켜는 일(⑤)을 막지 않는다.

### 3.10 `death` + `role` — **이 문서에서 다루지 않음(S1 SD3로)**

`champion`·`boss` 처치는 S1 3.3의 "수호자 처치"(−18~−15)·"우두머리 처치"(−16~−14) 줄과 A5 순서표에 이미 있다. 큰 순간의 덕킹(S1 6.4 `big_moment`)과 함께 가야 하므로 낱개로 넣지 않는다. 역시 꺼진 판에도 늘 실리는 필드다.

### 3.11 (숨은 줄) 원형의 `hit` → `impact` — **보내지 않는다**

RS5 목록에는 없지만 지금 코드에서 원형의 명중은 `impact`를 부른다(1.2, 1.4의 4). 3.1에서 맥박으로 접는다. 판별: `hit.skill_id`가 그 판의 원형 id(`run.spells.spells[id].role == "ring"`, 읽기 전용).

## 4. 맞물림 보상 소리의 방향 — "지금 조합이 먹혔다"

| 신호 | 사람이 알아야 할 것 | 소리가 하는 일 | 키우는 것 |
|---|---|---|---|
| I1 덧소리 | "멈춰 둔 적을 기본기가 더 세게 쳤다" — 두 스킬이 이어졌다 | 일반 명중 위에 **다른 원소의 결**이 짧게 얹힌다. 화염 마녀가 냉기를 빌려 왔다면 화염 명중 위에 얼음 "딩" — 빌린 짝(`pair.borrow.*`)이 귀로 들린다 | **보상**(고른 카드가 일하는 것이 들림), **쾌감**(손맛), **성장**(축을 올릴수록 잦아짐) |
| I2 터뜨림 | "기본기로 찍어 둔 표시를 원형이 터뜨렸다" | 맥박(작고 둔함) 바로 위에 크고 밝은 터짐. 많이 걸린 틱은 꼬리가 길어진다 | **보상**, **쾌감**, **도박**(같은 틱에 몇 개가 걸릴지 모름 → 큰 터짐이 가끔 옴) |
| 끊음 | "내가 막았다" | 맥박과 결이 다른 꺾임. 예고 소리가 생기면 그것을 끊는다 | **쾌감**, **보상**(차단 축을 올린 값) |

공통 규칙:
1. **대비가 보상이다.** 맞물림 소리는 맥박보다 6~10dB 크고, 맥박은 익숙해짐 감쇠로 더 낮아진다(3.1). 맞물림이 있었던 맥박은 감쇠를 0으로 되돌려 그 순간만 원래 크기로 돌아온다 — "지금 뭔가 일어났다"를 크기 변화로 알린다.
2. **성장이 들린다.** 축이 오르면 원형 쿨이 54 → 30틱으로 줄어 맥박이 잦아지고, 맞물림도 잦아진다. 소리 크기는 올리지 않는다(빈도로 성장을 들려준다). 진화(`evolved`)의 첫 발동은 S1 3.3 "진화 첫 발동" 줄이 이미 맡는다.
3. **도박은 작게.** 같은 틱 터뜨림 n ≥ 4의 긴 변주만. 무작위로 소리를 크게 하는 장치는 두지 않는다(결정론, 원칙 6).
4. **섹시는 이 문서에서 키우지 않는다**(0절).

## 8. 확인하지 못한 것

- **모든 소리의 청취**(에이전트는 들을 수 없다). 이 문서의 "성격 한 줄"은 모두 가설이다.

- 원형 명중이 `impact` 쿨을 먹어 버려지는 기본기 명중의 실제 비율(23%는 쿨만으로 셈한 위쪽 값) [모형].
- 동시 목소리 사용의 실제 값(3.12 끝의 0.7~1.5개는 길이와 빈도로 셈) [모형].
- Sonniss GDC 묶음의 EULA 원문, itch 두 묶음의 약관.
- 로컬 재료 파일 하나하나의 길이·대역(재지 않았다).

- 화면 쪽(A6-RS RS1·RS2)이 맥박·터짐을 어느 프레임에 그릴지 — 아직 구현 전이다.
