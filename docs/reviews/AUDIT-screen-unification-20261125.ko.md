## 5. 여쭐 것과 정할 것

### 5.1 사용자에게 여쭐 것

1. **등급색(A10 Q1, 아직 답 없음)**: 고유 장비 이름과 화염 글자가 거의 같은 색(ΔE 7)이고 다섯 등급 가운데 넷이 D21의 문턱을 넘지 못한다. 권고는 "(가) 등급색은 그대로, 화염 글자색·성장 금을 조금 옮김"이다. 묶음 B에서 장비 이름을 등급색으로 바꾸면 이 겹침이 화면에 더 많이 드러나므로 B 전에 답이 필요하다.
2. **장비창의 모양**: 묶음 B에서 겉만 새로 입히고(목록 + 비교), 마녀를 가운데 두는 인형 칸 배치(디아블로식)는 감정·자동 열림이 정해진 뒤 한 번 더 바꾸는 두 단계로 가도 되는가, 아니면 한 번에 인형 칸까지 갈 때까지 기다리는가.

### 5.2 디렉터가 정할 것

1. A(W9)와 B가 `chapter_hud.gd`를 잡는 차례. 권고: A 먼저(사용자가 이미 물은 화면), B는 A 병합 뒤.
2. K5·K7 그림의 대기열 실행 승인(비용은 asset-producer가 제시).
3. 장부 갱신: U-26·U-30·U-34의 상태 칸이 낡음(U-26 "명세 없음" → 실제는 들어감 `75e5d82`; U-30은 U-63으로 묶였는데 "명세 없음"). U-69의 "미커밋"은 `d65eba4`로 들어감.
4. 묶음 B의 통과 기준에 "같은 순간에 새 창과 옛 창이 겹치는 경로 0"(칸 8 같은 것)을 넣을지.
