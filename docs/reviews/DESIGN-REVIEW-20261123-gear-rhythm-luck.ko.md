## 6. 직접 한 것과 하지 못한 것

직접 한 것:
- 위 1절 머리의 파일을 모두 읽었다. 층 2의 RUN 줄에서 계열별 맨몸 수호자 처치 시간을 직접 뽑았다 [원시].
- `chapter_core.gd` 624~634행(구역에 들어가기 전 생성 없음), 758~776행(`_rhythm_tick`), 997~1041행(`_spawn_rhythm_wave`)을 읽었다 [코드]. `L2c_stand.txt`의 승2 구간 값(살아 있는 적 0.0)을 직접 봤다 [원시].
- `chapter1/core`에 포위 압력(`pressure`) 코드가 없음을 검색으로 확인했다(`combat_core` 794행의 `pressure`는 무리 밀침 변수).
- `python tools/dev/decision_ledger.py` 실행: 다음 빈 번호 N90·U30, `LEDGER PASS`.
- `python tools/dev/run_all.py --only decisions,wording`: 문서를 쓴 뒤 실행(결과는 보고에 적음).

하지 못한 것:
- 측정을 다시 돌리지 않았다. 90판·30판·18판·10,000판의 값은 모두 [보고]·[원시]다.
- 번개의 연쇄가 수호자 싸움에서 곁의 무리로 튄다는 것은 짐작이다(CB-G1의 `guardian_share`가 잰다).
- 자동 조작이 사격조 탄을 잘 피한다는 것은 확인되지 않은 소견이다(N97은 확인 대신 사람 대리 판을 더한다).
- 장부 범위: N90~N100·U30은 장부의 기본 범위 밖 문서(이 검수, D22·D23-T1·T11의 부록)에 있다. 다음에 `decision_ledger.py`를 돌린 사람에게도 N90이 빈 번호로 나온다. 디렉터가 `DECISIONS-PENDING`에 줄을 올리거나 범위를 넓혀야 겹침이 막힌다.
- 미평가: 장비를 낀 판의 쉬움, 가운데의 긴장, 몰아침이 터지는 순간, 가시의 되갚는 맛, 운 한 줄의 고민. 모두 사용자 플레이로만 채운다.
