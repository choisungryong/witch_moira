# 품질 목표

2026-11-15. 각 작업이 "끝났다"고 말하기 위한 기준이다. 숫자로 잴 수 있는 것은 숫자로, 사람만 판단할 수 있는 것은 질문으로 적는다. 사람 평가가 없으면 그 항목은 "미평가"로 남기고 통과로 적지 않는다.

## 1. 항상 지키는 기준

| 영역 | 기준 | 확인 방법 |
|---|---|---|
| 회귀 | `run_all.py` 전부 통과 | 명령 실행 |
| 스크립트 오류 | 실행 로그에 스크립트 오류 0건 | `run_dev.py` 실행 로그 |
| 성능 | 1920×1080 실행 빌드에서 프레임 시간 p95 16.6ms 이하, 50ms 넘는 끊김 0회 | 프레임 측정기 3회 |
| 저장 | 기존 저장 파일을 수정하지 않음. 새 저장은 재실행 뒤에도 그대로 읽힘 | 프로필 검사 |
| 결정론 | 코어를 고치지 않은 변경은 골든 리플레이가 그대로 | 골든 비교 |

성능 항목은 현재 **미달 상태로 추정**된다. 2026-11-14의 비공식 측정에서 후보49·51 모두 p95가 19~22ms였다(창 크기 조건 미달로 공식 판정은 아님). 전투 효과를 넣은 뒤로는 측정하지 않았다.

2026-11-15 측정(1920×1080, 수직 동기화 끔, 60~180초, 시드 11, 켬·끔 번갈아 3~4회 중앙값, 원시는 `perf/20261115-juice/`와 `perf/20261115-juice-fix/`): 전투 효과 끔 p95 15.15~16.27ms, 효과 켬 p95 16.42~16.64ms(효과 모듈을 고친 뒤). 켬과 끔의 차이는 0.4~1.3ms. 50ms 넘는 끊김은 끔에서도 회차마다 0~3회 나와 **미달**이다. p95는 목표 경계에 걸쳐 있어 달성으로 적지 않는다. 병목은 GPU가 아니라 CPU다(3D 해상도를 낮춰도 변화 없음). 이 측정은 전투 수치 조정(적·투사체 증가) 전의 장면이라, 조정 뒤의 값은 아직 없다.

### 정지 화면 한 장으로 확인하는 것

같은 시드, 같은 시점의 캡처를 놓고 본다.

1. 주인공이 어디 있는지 1초 안에 짚을 수 있다.
2. 적의 공격 전조가 주문 효과에 가려지지 않는다.
3. 세 계열(화염·냉기·번개)의 효과를 색을 지워도 형태로 구분할 수 있다.
4. 방금 적이 죽은 자리를 짚을 수 있다.
5. 우두머리를 일반 적과 구분할 수 있다.

### 사람이 플레이하고 답하는 것

1. 맞았다는 느낌이 소리 없이도 드는가.
2. 가장 좋았던 순간은 언제였나.
3. 지루했던 구간은 어디였나.
4. 죽었다면 왜 죽었는지 알았나.
5. 한 판 더 하고 싶은가.

## 3. 전투 화면 표시(HUD)

| 항목 | 기준 |
|---|---|
| 해상도 | 1280×720과 1920×1080에서 겹침·잘림 없음 |
| 가림 | 화면 가운데 가로 60%·세로 60% 영역을 표시가 가리지 않음 |
| 위급 신호 | 생명이 30% 아래일 때 구슬만 봐도 알 수 있음(색이나 움직임이 달라짐) |
| 읽기 | 스킬 칸은 글자 없이 아이콘과 재사용 표시만으로 상태를 알 수 있음 |
| 일관성 | 틀, 글꼴, 색이 한 가지 규칙을 따름 |
| 확장 | 필살기 칸과 영혼 게이지가 배치를 흔들지 않고 들어감 |

사람 평가: 처음 보는 사람이 설명 없이 생명·스킬·목표가 어디 있는지 짚을 수 있는가.

## 4. 장비와 득템

| 항목 | 목표 | 현재 |
|---|---|---|
| 한 판의 희귀 | 3~5개 | 시뮬레이션 4.6 / 실제 3 |
| 한 판의 장신구 | 1개 안팎 | 시뮬레이션 1.4 / 실제 1~3 |
| 전설 | 세 판에 한 번 | 시뮬레이션 0.37 |
| 유니크(첫 처치 제외) | 다섯 판에 한 번 | 시뮬레이션 0.23 |
| 착용 칸 | 한 판을 마치면 8칸 중 6칸 이상 착용 | 5~6칸 |

사람 평가: 좋은 장비가 떨어진 순간을 소리와 화면으로 알아챘는가. 주운 장비를 착용할지 3초 안에 판단할 수 있었는가.

## 5. 참고 대상과의 비교

SACRATA 영상의 같은 종류 장면(군중 전투, 레벨업 선택)을 우리 캡처와 나란히 놓고, 다음 다섯 가지를 각각 "뒤처짐 / 비슷함 / 앞섬"으로 적는다: 효과의 밀도, 빛과 대비, 캐릭터의 존재감, 화면 표시의 완성도, 큰 순간의 연출. 판정은 사용자가 한다.

2026-11-15 현재 제 판단으로는 다섯 항목 모두 뒤처져 있다. 가장 가까운 것은 효과의 밀도와 빛(이번 작업으로 좁혀지는 중), 가장 먼 것은 캐릭터의 존재감(3D 모델과 크기)이다.

## 6. 쓰는 법

- 단계를 마칠 때 해당 표의 "현재" 칸을 다시 재서 갱신한다.
- 목표에 못 미치면 못 미쳤다고 적는다. 목표를 결과에 맞춰 옮기지 않는다.
- 목표 자체가 틀렸다고 판단되면 이유를 적고 사용자와 정한 뒤 바꾼다.
