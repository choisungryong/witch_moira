# 지시 장부

총괄 디렉터가 관리한다. 사용자의 지시가 어디까지 갔는지를 한 표로 둔다(`docs/PROCESS-CHECKS.ko.md` 3절). 시간순 기록은 인계 메모에 있고, 이 문서는 "이 지시가 지금 어디 있나"를 본다.

상태: `명세 없음` → `명세` → `구현 중` → `구현(꺼짐)` → `켬` → `실측 통과` → `사용자 확인`.
"사용자 확인"은 사용자가 플레이하거나 보고 좋다고 한 것에만 쓴다. 모델의 답과 자동 조작의 측정은 "실측"에 적되 조건(판 수, 장비 유무)을 붙인다.

마지막 갱신: 2026-11-20.
