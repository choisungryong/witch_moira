## 계열별 세 방향

| 계열 | 집중 타격 | 넓은 지역·제어 | 지속·조건 연계 |
|---|---|---|---|
| 화염 | 집중 화염탄 → 관통 고열 → 단일 대상 폭발 | 불꽃 부채 → 폭발 확장 → 군집 연쇄 폭발 | 잔불 부착 → 연소 누적 → 연소 전파 |
| 냉기 | 서리창 → 관통 강화 → 빙결 관통 파쇄 | 서리 파동 → 둔화 지대 → 이동 경로 봉쇄 | 냉각 표식 → 빙결 촉진 → 조건부 파편 연쇄 |
| 번개 | 집중 전격 → 반복 타격 → 보스 집중 방전 | 연쇄 전류 → 갈래 확장 → 군집 연결망 | 감전 표식 → 충전 축적 → 조건부 광역 방전 |

위 표는플레이방식차이를먼저정의한다.같은투사체에피해수치만바꾸는세가지선택은완성기준을충족하지않는다. 각분기는보스/군중/위치제어중강점과기회비용을명시한다.기존진화는해당계열한분기의상위노드로재배치하고전부자동부여하지않는다.

## 그래프·포인트 계약

노드는id/owner_character_id/branch_id/kind/max_rank/prerequisites/min_spent_points/cost/effect_id/synergies를가진다.노드ID는저장호환용고정키로사용한다.진입시대표기술기본1랭크를보장한다.추가포인트는플레이보상으로지급하며선행투자·가용포인트·캐릭터소유권을코어에서검증한다.이미사용한포인트는사용가능량에서차감한다.다른계열전용노드는획득·랜덤선택·장비부여경로모두거부한다.장비강화는소유기술효과를수정하며다른캐릭터전용기술을해금하지않는다.

초기분기는혼합투자가가능하게설계하고,최종특화는투자깊이로제한한다.최종노드상호배타규칙은콘텐츠시험후확정한다.포인트와랭크시너지는별도로계산해장비보너스가선행조건을우회하지않도록한다.자동시전은유지하면서범위·주기·방향·상태이상·조건부폭발이분기마다달라져야한다.

공용기술은별도공용풀에두고전용트리와같은투자자원/슬롯을소비하는방향으로검토한다.공용기술예시는비전구체·보호막이며아직게임기술로추가하지않았다.공용기술목록이비어있는현재character52는성장연결준비완료로승인하지않는다.

## UI·관리 툴

선택창에는캐릭터이름/전용계열/세분기요약/시작기술을보여준다.트리에는연결선·잠금이유·현재/다음효과·필요포인트·소모후잔여량을표시한다.트리열람은전투를정지하고첫범위의투자·재분배는안전한준비화면에서확정한다.재도전·초기화·취소의동작을명시한다.관리툴은캐릭터→트리→분기→노드→효과/원본/작업상태를읽기전용카탈로그로연결한다.현재범위는관리툴에서게임수치를직접편집하지않는다.

## 실행 순서와 완료 근거

1. 캐릭터 소유권 정책과 그래프 데이터/검증기를 마련한다. 순환·없는 선행노드·다른캐릭터연결·포인트초과·미해금효과를 거부한다.
2. 냉기 계열의 서로 다른 세 분기를 먼저 실제로 동작시켜 전투 차이를 확인한다. 공용 기술 한 묶음과 선택·투자 UI를 연결한다.
3. 같은 구조로 화염·번개를 확장한다. 합법적인 혼합 빌드와 극단적인 집중 빌드를 둘 다 검사한다.

5. 세 캐릭터 실제 선택→진입→분기투자→스킬효과→장비시너지→종료까지 플레이한다. UI테스트통과나정적그림만으로빌드재미완료를주장하지않는다.
