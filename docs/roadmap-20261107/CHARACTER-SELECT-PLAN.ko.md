# 캐릭터 선택과 시작 마법 — 검토안

2026-11-14 사용자 우선순위: 주인공 에셋은 유지하고 게임성과 기능부터 진행한다. 여성 주인공3~4명 중 선택, 각 전용 마법으로 시작하는 구상을 검토한다. 대표 마법의 캐릭터 독점+별도 공용 기술 조합은 사용자 확정 사항이다. 인원·이름은 미확정이다. 같은계열여러분기요구는SKILL-TREE-PLAN.ko.md에확장했다.

## 권장 첫 범위

기존 화염/냉기/번개 시작 경로를 활용한3명으로 먼저 구성한다. 화염은 범위·연쇄 폭발, 냉기는 관통·감속·빙결, 번개는 연쇄·기절 스타일을 설명한다. 기존 주인공 모델과 초상을 유지하며 별도 외형이 준비됐다고 표시하지 않는다. 네 번째는 역할과 기술이 정해진 뒤 추가한다.

현재 코드에는 primary_skill로첫랭크1을초기화하는계약이있다.이를character_id→starting_skill_id 정의로연결한다.첫출발·재도전에서같은선택을유지하고성장·진화·장비흐름과실제값표시를검증한다. 기존 저장schema는엄격한키검사를하므로캐릭터저장항목을임의로추가하지않는다.첫범위는도전중선택유지이며영구저장여부는별도설계한다.

## 단계

1. 캐릭터 정의와 선택 화면: 정체성/전투 스타일/시작 마법을 보여주고 선택·출발을 연결한다. 기존 임시 외형 공유를 명확히 한다.
2. 서로 다른 시작과 재도전·성장·진화·장비 연결 검증. 현재 전용이라는 표현이 시작 보장인지 타 캐릭터 습득 금지인지 확정한 뒤 기술 풀을 변경한다.
3. 세 캐릭터 체감 차이를 플레이로 비교하고 필요한 고유 특성·공용 기술을 설계한다. 단순 이름 변경을 플레이 스타일 완성으로 표시하지 않는다.
4. 후속 네 번째 역할과 새 전용 마법·효과·밸런스는 별도 묶음으로 구현한다.

## 비용 판단

3명 선택과기존3시작기술연결은기존구조확장으로대규모재작성은필요없다.새마법·전용패시브·개별모델/동작·캐릭터별저장까지한번에묶으면범위가커진다.현재는첫범위를작게완성한뒤확장한다.일정시간은실행증거없이확약하지않는다.
