# 캐릭터 영구 성장과 챕터 밸런스

2026-11-14 사용자 확정: 캐릭터별 스킬트리 투자는 영구 저장한다. 캐릭터마다 전용 대표 마법을 가지고 공용 기술을 조합하며, 전용 계열 안에도 여러 분기를 둔다. 챕터별 밸런스를 세심하게 설계한다. 주인공 에셋은 현재 것을 유지한다. 이 문서는 구현 계획이며 새 성장 체계가 제품에 반영됐다는 뜻이 아니다.

## 현재 구조와 전환 범위

현재run_growth는도전시xp/레벨/기술랭크/패시브/진화를초기화한다. chapter_profile-v1은장비/재/완료횟수만저장하며엄격한키검사를한다. 새영구성장은메뉴만바꾸는작업이아니라성장보상·저장·진입스냅샷·재도전·초기화·챕터난이도계약을함께전환하는기능이다.

현재제1장의세공간(잿빛앞뜰/무너진성가대/재의성소)은한챕터안의구역이다. 제2·3장콘텐츠가이미존재한다고취급하지않는다. 먼저제1장세구역안에서초반/중반/보스성장을검증하고후속챕터의입장기준을정의한다.

## 영구 상태와 도전 상태

캐릭터별 영구 상태: character_id, level, xp, earned_skill_points, spent_skill_points, node_ranks, highest_cleared_chapter, reward_receipts, revision. 공용보관함의기존장비와캐릭터별착용슬롯의소유관계는명시적으로분리한다. 기존장비와현재착용을새캐릭터에자동복제하지않는다. 초기이관시기존착용은기존진행캐릭터에연결하고나머지는공용보관함에서명시적으로장착한다는안을검토한다.

도전 상태: 현재 생명/회복약/적/현재 구역/일시적 강화/미회수 전리품. 사망·재도전으로영구레벨과투자노드는사라지지않는다. 출발시검증된영구빌드와착용장비의읽기전용스냅샷으로전투를초기화한다. 도전중빌드변경시효과전환/생명상한보정이필요하므로첫범위의투자는안전한준비화면에서확정한다.

기존레벨업선택의대표마법자동랭크상승은영구트리와중복시키지않는다. 영구레벨업은포인트획득으로연결하고투자가능알림을표시한다. 전투중랜덤선택을유지할경우일시적유물/도전강화로역할을분리한다. 어느선택이영구인지일시적인지UI에명시한다.

## 챕터 난이도 계약

챕터/구역마다권장레벨범위·보유포인트범위·기대장비강도·적종류/밀도·적생명/공격·보스패턴·보상XP를별도데이터로관리한다. 수치확정은냉기3분기실제시뮬레이션과조작플레이후에한다. 현재FULL_XP나SEAL_KILLS를새성장에그대로사용하지않는다.

캐릭터가강해진만큼일반적생명과공격을즉시같이올리는자동동기화는첫범위에넣지않는다. 각챕터의기본난이도를고정해이전지역에서강해진체감을준다. 적의어려움은생명상승뿐아니라원거리/돌진/전조/지형/군중조합으로구성한다. 고난도변형은기본클리어루프와분리한다.

기준빌드행렬: 캐릭터3종×각주분기3종,각각최소입장/권장/성장완료상태와낮음/보통/높음장비강도를비교한다. 첫구현은냉기3분기의단일대상·군중·생존과혼합빌드를검증한뒤확장한다. 모든분기가같은초에클리어해야하는것은아니지만기본진행이막히는분기는출시하지않는다.

관측지표: 일반적처치시간,군중정리속도,보스처치시간,첫피해/첫사망시점,단위시간받은피해,회복약소비,포인트획득속도,구역완료시간,재도전횟수. 평균DPS만으로회피·빙결·광역강점을평가하지않는다. 목표범위와측정조건은각시험전에기록해결과에맞춰합격선을이동하지않는다.

## 보상·반복·실패

일반경험치는확인된처치이벤트,큰보상은수호자/챕터최초완료영수증으로관리한다. 동일최초보상으로영구포인트를반복발급하지않는다. 재도전에서장비와일반경험치를얻는성장경로는허용한다. 과도한반복으로차기챕터가무의미해지는문제는고정챕터XP효율과보상곡선을측정한뒤조정하며소리없는보상차단을넣지않는다.

사망전정상획득경험치의보존시점은저장체크포인트계약으로정한다. 보스/영구포인트보상은run_id+event_id로멱등처리한다. 종료/실패/재접속으로중복수령또는현재진행롤백이생기지않아야한다. 검증실행은실사용프로필에경험치를추가하지않는다.

## 재분배와 저장

제1장검증기간에는준비화면무료재분배를권장해세분기를실제로비교할수있게한다. 포인트환불후선행조건이깨지는하위노드는함께되돌리거나요청을거부하며이유를표시한다. 전투중임의환불은첫범위에서지원하지않는다. 비용을부과하는장기정책은후속밸런스판단으로남긴다.

기존v1파일은그대로보존한다. 새schema와별도후보저장경로에일회이관하고이관전후해시·출처revision을남긴다. 검증된임시파일작성→검증→원자적교체→revision/journal순서를설계한다. 실패시기존원본을삭제하거나과거저장으로덮어쓰지않는다. 캐릭터전환·재도전·종료·충돌/재실행·중복영수증·손상파일거부·재분배후의선행관계를각각검사한다.

## 구현 순서

1. 캐릭터영구상태/보상소유권/스킬그래프의데이터계약과검증기를구현한다. 기존v1저장과런코어는이단계에서수정하지않는다.
2. 냉기캐릭터와공용기술의완결된작은트리를만들고준비화면투자·재분배·재실행지속을검증한다.
3. 제1장세구역의적·보상·레벨곡선을이성장체계에맞춰측정·조정한다. 새전투상태에서시작/재도전/성장스냅샷을연결한다.
4. 화염·번개와세캐릭터선택을같은체계로확장하고빌드행렬을검증한다. 관리툴에캐릭터별트리/챕터기대강도/미검수상태를연결한다.
5. 최종조립후성능·전체조작플레이·저장연속성을확인한다. 이전후보검사성공을새영구성장제품성공으로승계하지않는다.
