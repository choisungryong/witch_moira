# 계열 필살기 스택과 주인공 시전 컷인

2026-11-14 사용자 요구: 각 계열의 필살기 스택이 일정량에 도달하면 필살기 효과를 시전한다. 화면 전체에 화려한 효과와 함께 주인공이 실제 시전하는 모습을PV처럼 보여준다. 주인공 에셋은기존것을유지하고게임성·기능을우선한다.

## 영구 성장과 전투 스택

캐릭터별 필살기 해금·강화·분기 특화는영구트리. 필살기충전량·현재시전·전투중대기는도전상태다.첫범위는기본필살기를처음부터체험하고상위트리투자로분기별성격을강화하는안을권장한다.구체적해금시점은챕터곡선검증후확정한다.맵이동중적이없는시간에자동충전하지않고사망/새도전시스택초기화,모달/일시정지는그대로유지한다.

대표 마법의 확인된 명중/상태이상 기여로충전한다.연쇄대상수·투사체수·도트틱마다무제한으로적립하지않도록시전이벤트단위중복제거와최소적립간격을둔다.군중형/보스형/제어형분기의도달시간을비교한다.필살기피해가다시자기스택을채우는순환은차단한다.다른캐릭터전용마법이나메뉴행동은적립대상이아니다.

기본발동은최대스택도달후다음전투가능시점자동시전.선택/장비/정지화면에서는준비상태를유지하고복귀후발동한다.발동시스택을한번만소비해cast_id를발급한다.중복콜백/저장실패/연출재생완료가공격을다시발동시키지않아야한다.공격시작과연출시작의소유권은코어에둔다.수동전환은후속조작정책으로검토한다.

## 세 계열 연출과 기능 초안

| 계열 | 기능 방향 | 시전 장면 방향 |
|---|---|---|
| 화염 | 넓은지역의큰폭발과잔화,군중정리 | 주인공이불꽃을모아전방에해방,화면가장자리까지화염파문 |
| 냉기 | 광역냉각/빙결과파쇄,제어가치 | 주인공이빙결인장을펼치고서리파동확산,균열과빙정파쇄 |
| 번개 | 다중대상방전과집중낙뢰,대상선정가치 | 주인공이전류를모아내려찍고화면전역연결망발광 |

화면전체를채우는시각효과와실제공격범위는구분해설명한다.모든적즉사/무조건보스동결로설계하지않는다.보스제어감쇠·피해상한·각분기의기회비용을측정한다.각계열3분기가별개PV9개를필수로요구하지않고공통기본시전에분기특화효과를조합한다. 이름·피해·스택량·적립주기는아직최종수치아니다.

## PV 같은 실시간 컷인

현재 주인공 모델과 실제 cast clip을 별도근접카메라/조명으로짧게보여주고필살기타이밍에전장으로돌아온다.첫시안은약0.8~1.2초를목표로하되측정후조정한다.단순초상확대나가짜애니메이션을실제주인공시전으로표시하지않는다.외부영상제작과별개로현재게임모델을활용한실시간연출을우선한다.

준비→시전컷인→공격해결→복귀를한상태기로관리한다.컷인동안전투시뮬레이션을정지하는방향을검토하되전투UI/선택/입력해제와논리시간을함께관리한다.정지한장면에서초단위쿨다운이별도로흐르지않게한다.연출을건너뛰거나간소화해도동일cast_id의같은공격을한번만처리한다.정확한순간판정과타깃스냅샷은프로토타입에서검증한뒤확정한다.

모션감소/간소화설정에서는짧은시전표시와같은판정을제공한다.빈번한반복PV로플레이호흡이끊기지않도록목표발동빈도와스킵동작을검수한다.충전게이지는현재/최대·준비/시전상태를표시하고전투중큰설명창을띄우지않는다.

## 구현 순서

1. 미연결스택상태기:적립소유권/중복방지/적립간격/최대량/모달대기/한번소비를검증한다.실제전투나PV완료를뜻하지않는다.
2. 캐릭터영구트리·분기코어와연결,냉기필살기의실제명중/빙결/파쇄를먼저구현한다.
3. 현재모델실제시전컷인과전장광역효과·스킵·간소화·정지복귀를연결한다.
4. 화염/번개와분기변형으로확장하고보스/군중/제어빌드별충전·처치·연출빈도를비교한다.
5. 관리툴에필살기정의·스택규칙·시전클립·효과·검수상태를연결한다.원시·이전후보·사용자저장은보존한다.
