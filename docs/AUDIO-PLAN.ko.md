## 2. 첫 일 — `audio-lead`의 조사와 방향 문서

산출물: `docs/specs/S1-audio-direction.ko.md`. 문서만 쓴다.

1. **재고 조사**: 지금 음원 22개를 재서 표로(길이, 최대 음량, 평균 음량, 잘림, 앞뒤 무음, 대역 요약). 재생 코드가 어떤 이벤트에 어떤 소리를 얼마나 자주 내는지(한 판을 헤드리스로 돌려 이벤트별 재생 요청 수와 동시 발음 수의 분포). 군중 전투에서 초당 몇 번 울리는가.
2. **소리 목록**: 3절의 초안을 고쳐 확정한다. 소리마다 사양(길이, 대역, 어택, 변주 수, 목표 음량, 우선순위, 쓰이는 코어 이벤트).
3. **믹스 규칙**: 버스 구성, 목표 음량, 동시 발음 상한, 덕킹.
4. **음악의 구조**와 생성 도구의 비교(비용·권리·품질을 잴 방법). 유료는 값을 제시한다.
5. **사용자의 청취 계획**: 무엇을 어떤 순서로 들려 드리고 무엇을 여쭐지(5절).
6. `sound-designer`에 내릴 지시서의 단위와 순서.

## 3. 소리 목록 초안

우선순위: 가 = 한 판의 첫인상에 필요, 나 = 제1장 완주판에 필요, 다 = 뒤에.

| 묶음 | 소리 | 우선 | 메모 |
|---|---|---|---|
| 전투, 주인공 | 세 계열의 시전과 명중(계열마다 변주 3~4), 진화한 주력의 소리, 회피, 물약, 피격, 위급 신호(생명 30% 아래의 맥박) | 가 | 세 계열이 눈을 감고도 갈려야 한다: 화염은 낮고 두꺼운 터짐과 타닥거림, 냉기는 높고 맑은 깨짐, 번개는 짧고 날카로운 터짐과 잔향(대역으로 지시한다) |
| 전투, 적 | 예고(일반·원거리·돌격·정예·우두머리), 공격, 처치(묶음 재생) | 가 | 예고는 전용 버스. 효과의 소리가 덮지 못한다 |
| 큰 순간 | 레벨업과 은총 화면의 등장, 은총 고르기, 진화, 구역 봉인 해제, 수호자 등장과 처치, 우두머리 처치, 승리, 쓰러짐 | 가 | `docs/specs/A5-combat-light-effects-direction.ko.md`의 순서표와 맞춘다. 큰 순간에는 나머지를 낮춘다 |
| 득템 | 등급별 드랍(일반은 거의 무음, 희귀·전설·고유는 뚜렷이), 장신구, 줍기, 더 좋은 장비 알림, 착용, "봉인 풀기" 장면(봉랍이 갈라짐, 드러남) | 가(드랍·줍기) / 나(봉인 풀기) | `docs/specs/D10-seal-reveal-scene-spec.ko.md` |
| 화면 | 초점 이동, 확인, 취소, 창 열고 닫기, 스킬 트리 투자와 확정, 저장 거부 안내 | 가 | 재질이 "장정과 실"이다: 가죽, 황동 걸쇠, 종이, 봉랍의 소리 |
| 환경 | 구역별 환경음(앞뜰, 성가대, 성소 등 지금 구역 셋), 날씨, 발걸음(바닥 재질별) | 나 | 지금 환경음 1개 |
| 음악 | 타이틀·메뉴, 캐릭터 선택, 판(구역별 층 또는 강도 단계), 수호자·우두머리, 승리, 쓰러짐, 은총 화면의 짧은 동기 | 가(타이틀, 판 한 곡, 우두머리) / 나(나머지) | 4절 |
| 목소리 | 세 마녀의 기합과 피격(대사 없음), 어머니의 존재 신호(화염: 불빛의 소리, 냉기: 바람이 멎음, 번개: 0.4초의 무음) | 나 / 다 | 존재 신호는 `docs/story/BOON-SCREEN-FIGURE-RULES.ko.md`. 대사 녹음은 결정 N38(나중) |

군중 전투의 규칙(초안): 같은 틱의 명중·처치는 한 번으로 묶고 수에 따라 음량과 음높이만 올린다. 같은 소리의 연속 재생 최소 간격 60ms, 종류마다 동시 발음 상한을 둔다. 값은 재고 조사 뒤에 정한다.

## 4. 음악

- **구조(초안)**: 판의 음악은 한 곡을 강도 단계(잔잔함 / 무리 / 수호자·우두머리)로 나눠 겹치거나 갈아 끼운다. 구역이 바뀌어도 끊기지 않게 박자 단위로 넘긴다. 타이틀과 캐릭터 선택은 같은 주제의 조용한 판.
- **분위기**: 고딕 다크 판타지, 무너진 수도원. 악기와 템포, 조성은 `audio-lead`가 잴 수 있는 말로 정한다(예: 템포 범위, 저음 지속음의 대역, 합창·현·종의 쓰임). "웅장하게" 같은 말로 끝내지 않는다.
- **만드는 길**(사용자가 정할 것, 6절): (가) 음악 생성 AI — 빠르고 싸지만 권리와 약관, 스팀의 AI 공개, 반복 구간 편집이 필요하다. (나) 공개 라이선스 음악 — 비용이 없지만 맞는 곡을 찾아야 하고 다른 게임과 겹친다. (다) 작곡가 외주 — 품질과 권리가 분명하지만 비용이 가장 크다. 권고는 (가)로 시안과 임시 음악을 먼저 만들어 방향을 잡고, 출시 전에 (다)를 검토하는 것이다. 도구별 값과 약관은 `audio-lead`가 조사해 제시한다(이 문서를 쓰면서 조사하지는 않았다).
- 다른 작품의 선율을 본뜨거나 실존 음악가의 이름을 생성 지시에 쓰지 않는다.

## 5. 듣는 사람은 사용자뿐이다

에이전트는 소리를 들을 수 없다. 그래서 검증을 두 갈래로 나눈다.

| 갈래 | 누가 | 무엇을 |
|---|---|---|
| 잴 수 있는 것 | `sound-designer`가 재고 `audio-lead`가 검수 | 길이, 최대·평균 음량, 잘림, 무음, 대역, 반복 이음매, 동시 발음 수, 이벤트 연결, 프레임 시간, 파일 크기 |
| 귀로만 아는 것 | 사용자 | 어울리는가, 타격감이 있는가, 세 계열이 갈리는가, 거슬리는 소리가 있는가, 오래 들어도 피곤하지 않은가, 음악이 판의 흐름과 맞는가 |

사용자가 듣는 방법:
1. **시청용 묶음**: `sound-designer`가 `_local/audio/audition/<날짜>/`에 이름표가 붙은 파일과 비교 파일, 질문 목록을 만든다. 디렉터가 사용자에게 보낸다. 사용자는 다른 기기에서도 듣는다.
2. **전투 영상**: 자동 조작 한 판을 소리와 함께 녹화해 보낸다(가능한지 확인이 필요하다. 지금 캡처 도구는 화면만 뜬다).
3. **플레이**: 관리 툴 「플레이 기록」에 소리 질문을 더한다(`manager-tools`).

사용자의 청취 기록이 없는 소리는 "미평가"다. 통과로 적지 않는다.

## 6. 사용자가 정할 것

| 번호 | 결정할 것 | 선택지 | 권고 |
|---|---|---|---|
| A-1 | 효과음을 만드는 길 | 합성과 가공(비용 없음, 지금 방식) / 공개 라이선스 음원 / 효과음 생성 AI | 합성과 가공을 기본으로, 모자란 것(목소리, 금속·가죽 같은 실물의 소리)만 공개 라이선스나 생성 도구로. 내려받기와 유료는 건마다 승인 |
| A-2 | 음악을 만드는 길 | 생성 AI / 공개 라이선스 / 외주 | 생성 AI로 시안과 임시 음악, 출시 전에 외주 검토. 도구와 값은 조사 뒤 제시 |
| A-3 | 목소리 | 기합과 피격만 / 대사 녹음까지 | 제1장은 기합과 피격만 |
| A-4 | 소리 작업의 시점 | 지금 병행 / 성능 최종 측정 뒤 | 방향 문서와 재고 조사, 화면 소리와 큰 순간의 소리는 지금. 전투 소리의 반영은 성능 측정과 효과 개편(A5) 뒤 |
| A-5 | 음악 생성 도구에 계정이 필요할 때 | 사용자가 가입 | 가입과 약관 동의는 사용자가 직접 한다 |

## 7. 순서

1. `audio-lead`: 재고 조사와 방향 문서(2절). 문서만.
2. 사용자: A-1~A-5 결정, 지금 음원 22개의 시청(처음 듣는 것이므로 여기서 방향이 잡힌다).
3. `sound-designer`: 측정 도구와 시청용 묶음 도구 → 화면 소리 → 큰 순간의 소리 → 득템 → 전투(성능 측정 뒤) → 환경음.
4. 음악: 도구가 정해지면 타이틀과 판 한 곡, 우두머리의 시안.
5. 재생기를 `chapter_one.gd`에서 떼어 내는 일과 음량 설정의 저장은 `tech-lead`의 지시서를 거친다(설정 파일은 번역의 언어 설정 T3-L5와 같은 파일이다).
6. 출시 문서(T4)에 음악과 효과음의 출처·권리 원장, 스팀의 AI 생성 콘텐츠 공개를 더한다.

## 8. 확인하지 못한 것

- 지금 음원 22개가 어떻게 들리는지(아무도 듣지 않았다), 그 측정값.
- 재생 코드의 실제 구조와 이벤트 연결(이번에 다시 읽지 않았다).
- 음악과 효과음 생성 도구의 값과 약관, 품질.
- 소리가 든 전투 영상을 녹화할 방법.
- 참고작의 소리.
