## 8. 운영

- **원장에 올릴 것**: Quaternius Universal Animation Library·Universal Base Characters, Mixamo 동작, HY 3D 모델, Dreamina 영상 — 본체에 들일 때 "출시 전 약관 확인"으로.
- `CLAUDE.md`의 낡은 세 곳(저장 절, 옛 층 설명, 회귀 소요 시간)과 Python 경로 — 사용자 허락 대기(11-19부터).
- PC 이사(U-60): 옛 PC에서 계속 중. 옮기기 직전에 `python tools/dev/move_bundle.py --out D:/witch-moira-move-20261120.zip --update`. D 드라이브의 `witch-moira-work`(모델·영상·Dreamina CLI)가 커졌음.
- C 드라이브: 사용자가 손으로 비워 45GB. 담당 작업 폴더는 끝나면 치운다. `C:\out` 빈 폴더는 사용자가 지울 것.
- 쓰지 않는 에셋을 배포 묶음에서 빼도 되는지 — 사용자 답 대기.
- 측정이 시끄러웠던 것은 조용한 환경에서 한 번에: 메테오, 경계 담, 새 몸, 파이어볼, 둘레 효과, 은총 화면.
