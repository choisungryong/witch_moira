# 핵심 시스템 설계 — 서사·성장·장비·마을

2026-11-14, 2판. `DIRECTOR-PLAN.ko.md`의 보완 문서다. 1판(여신 주인공안)에 대한 사용자 검토를 반영했다. 수치는 출발 가설이며 구현·검증된 것이 아니다.

## 0. 사용자 확정 사항

1. **스킬 시스템**: 레벨업으로 스킬포인트를 얻어 스킬트리에 투자한다(디아블로2식 영구 성장).
2. **장비 시스템**: 디아블로식 드랍과 착용. 희귀·전설·유니크를 얻는 재미.
3. **득템과 성장의 재미**: 전투는 뱀서류, 재미의 뼈대는 파밍·보스 보상·성장.
4. **융합**: 디아블로2 레저렉션의 성장·아이템 문법 + SACRATA의 화려한 이펙트와 전투 방식.
5. **레벨업 구조**: 캐릭터 레벨업은 영구 스킬포인트, 판 안의 성장은 은총 카드.
6. **서사(2판 확정 방향)**: 주인공은 여악마의 힘을 빌린 인간이다. 이야기가 진행되며 그 힘을 극복하고 인간성을 되찾는다.
7. **게임 구성(2판)**: 마을에서 각 던전으로 입장하는 디아블로식 구성. 스토리를 넣는다.
8. **장비 비교(2판)**: 주울 때마다가 아니라 더 좋은 장비를 주웠을 때만 알린다.
9. **장신구(2판)**: 반지와 목걸이는 드물게 떨어지고, 떨어질 때의 경쾌한 소리가 살아야 한다.
10. **캐릭터 원칙**: 매력적인 성인 여성 캐릭터. 다른 게임의 캐릭터를 가져오거나 닮게 만들지 않고 고유하게 설계한다.

## 1. 한 줄 정의

여악마와 서약한 마녀가 되어 몰려오는 군세를 주문으로 쓸어 버리고, 전리품과 스킬포인트로 강해지며, 끝내 그 서약을 넘어서는 군중 생존 ARPG.

## 2. 서사의 뼈대 — 서약

### 2.1 구도

| 층 | 누구 | 게임 안의 자리 |
|---|---|---|
| 주인공 | 인간 마녀. 살아남기 위해 여악마와 서약했다 | 조작하는 캐릭터. 3D 모델 |
| 후원자 | 여악마. 힘을 빌려주고 대가를 받는다 | 은총 화면, 필살기 컷인, 마을의 제단. 2D 일러스트 |
| 대가 | 힘을 쓸수록 인간성이 깎인다 | 이야기의 축. 수치 시스템으로 만들지는 5.4에서 결정 |

이 구도가 지금 게임과 맞물리는 지점:
- 게임에 이미 "서약"이라는 말이 쓰인다. 성장 카드의 버튼이 "서약 선택"이고 타이틀 초상의 이름이 "서약의 마녀"다.
- 은총 카드가 이야기의 의미를 얻는다. 카드를 고르는 것은 여악마의 유혹을 받아들이는 일이다.
- 필살기는 여악마가 직접 모습을 드러내는 순간이 된다. 컷인의 주인공이 여악마다.
- 매력적인 여악마 일러스트가 들어갈 자리(은총 화면, 컷인, 제단)가 설정상 자연스럽다.
- 여악마는 2D만 있으면 된다. 3D가 필요한 것은 주인공뿐이라 에셋 부담이 줄어든다.

### 2.2 등장인물(임시 호칭, 이름은 사용자가 정함)

| 주인공(인간) | 서약한 여악마 | 계열 | 세 분기 |
|---|---|---|---|
| 잿불의 마녀 — 화형대에서 살아 돌아온 여자 | 잿불의 여악마 | 화염 | 집중 폭발 / 불꽃 부채·군집 연쇄 / 잔불·연소 전파 |
| 서리의 마녀 — 얼어붙은 수도원의 마지막 수녀 | 서리의 여악마 | 냉기 | 서리창 관통 / 서리 장판·경로 봉쇄 / 냉각 표식·파편 연쇄 |
| 뇌우의 마녀 — 벼락을 맞고 깨어난 기사 | 뇌우의 여악마 | 번개 | 집중 전격 / 연쇄 전류·연결망 / 감전 표식·광역 방전 |

주인공의 배경은 제안이다. 분기 구성은 기존 `SKILL-TREE-PLAN.ko.md`를 따른다.

### 2.3 이야기의 흐름(제안)

| 막 | 내용 | 게임에서 |
|---|---|---|
| 1막 서약 | 힘이 필요했다. 빌린 힘으로 회랑의 군세를 뚫는다 | 제1장. 은총은 달콤하고 대가는 보이지 않는다 |
| 2막 대가 | 힘을 쓸수록 무엇을 잃는지 드러난다. 여악마의 목적이 보인다 | 은총에 대가가 붙은 카드가 섞인다. 마을 사람들의 태도가 변한다 |
| 3막 극복 | 서약을 깨거나 다시 쓴다. 인간으로서의 힘을 찾는다 | 최종장. 후원자와의 대결 또는 결별. 서약 없이 쓰는 힘 |

이야기 전달은 가볍게 시작한다: 마을 인물의 대사, 던전 입장 전후의 짧은 문장, 우두머리 전후 대사, 장 시작의 그림 한 장. 컷신과 음성은 뒤로 미룬다.

## 3. 게임 구성 — 마을과 던전

```
마을(허브)
 ├─ 서약의 제단   : 스킬트리 투자·재분배, 여악마와의 대화
 ├─ 보관함        : 공용 장비 보관, 착용
 ├─ 대장장이      : 해체, "재"로 접사 재굴림
 ├─ 상인(후속)    : 구매·도박
 ├─ 이야기 인물   : 장마다 대사가 바뀜
 └─ 던전 입구     : 열린 던전 선택 → 입장
        ↓
던전(지금의 3구역 연결 원정) → 우두머리 → 전리품 → 마을 귀환
```

- 지금의 "준비 화면"이 마을이 된다. 트리 투자, 보관함, 출발이 모두 마을에서 일어난다.
- **마을 0판**: 걸어 다니는 3D 마을이 아니라 한 화면짜리 허브(장소를 고르는 그림 + 인물)로 시작한다. 기능이 먼저 서고 나면 걸어 다니는 마을로 바꾼다.
- 던전은 여러 개가 된다. 제1장의 세 구역을 하나의 던전으로 두고, 이후 던전을 추가한다. 던전마다 권장 레벨, 적 구성, 우두머리, 보물 등급표를 가진다.
- 던전 안의 구역 관문에서도 트리 투자를 허용한다(판 중간에 강해지는 순간).

## 4. 성장 — 두 층

### 4.1 영구 층: 캐릭터 레벨과 스킬트리

| 항목 | 설계 | 현재 구현 |
|---|---|---|
| 경험치 | 처치·우두머리·던전 완료로 획득, 주인공별로 영구 누적 | 판마다 초기화되는 `run_growth` |
| 레벨 | 제1장 범위 1~20(가설). 레벨당 스킬포인트 1 | 판 안 레벨 1~12 |
| 추가 포인트 | 우두머리 첫 처치, 던전 첫 완료(영수증으로 중복 방지) | `skill_tree52`에 규칙 있음, 미연결 |
| 트리 | 주인공당 3분기 + 필살기 노드 + 공용 노드 | 냉기 8노드 초안 |
| 투자 | 마을의 제단과 던전의 구역 관문. 제1장 검증 기간에는 무료 재분배 | UI 없음 |
| 레벨업 순간 | 생명 일부 회복, 화면 연출, "투자 가능 포인트 +1" | 없음 |

### 4.2 판 안의 층: 여악마의 은총

| 항목 | 설계 |
|---|---|
| 재화 | 영혼. 지금의 경험치 구슬을 영혼으로 바꾼다 |
| 발동 | 영혼 게이지가 차면 전투가 멈추고 은총 3장 중 1장 선택. 화면에 후원 여악마의 일러스트 |
| 카드 종류 | **변형**(트리 스킬의 형태를 바꿈) / **증폭**(조건부 강화) / **대여**(다른 여악마의 기술을 이번 판 동안 사용) / **수호**(생존) |
| 등급 | 카드 레벨 1~3 |
| 수명 | 판이 끝나면 사라진다 |
| 대여 제한 | 동시에 2개까지. **대여 기술의 피해 비중은 주력 계열을 넘지 않게 설계한다**(목표: 전체 피해의 30% 이하, 시뮬레이션으로 검사) |

두 재화의 구분: 경험치는 처치 즉시 화면 아래 얇은 줄(영구, 금색)에 쌓이고, 영혼은 구슬을 주워야 은총 게이지(판 안, 계열 색)에 쌓인다. 줄의 위치와 색을 다르게 두고 영구·일시 표시를 항상 붙인다.

지금의 3택 시스템(`run_growth`의 카드·토큰·가중 추첨·모달)을 그대로 쓰고 카드 내용만 바꾼다. 기존 "기술 랭크 상승"과 "진화" 카드는 트리로 옮긴다.

## 5. 장비 — 디아블로식 파밍

### 5.1 슬롯 8칸

| 슬롯 | 맡는 능력의 방향 | 드랍 |
|---|---|---|
| 무기 | 주문 피해, 투사체 형태 | 보통 |
| 머리 | 재사용 시간, 영혼 획득 | 보통 |
| 몸통 | 생명, 피해 감소 | 보통 |
| 장갑 | 시전 속도, 치명 | 보통 |
| 신발 | 이동 속도, 회피 재사용 | 보통 |
| 목걸이 | 스킬 랭크 +, 큰 효과 한 줄 | **드묾** |
| 반지 ×2 | 범용 접사, 조합의 빈칸 채우기 | **드묾** |

- 지금의 4칸(무기·몸·부적·반지)에서 머리·장갑·신발을 더하고, 부적을 목걸이로, 반지를 2칸으로 바꾼다.
- 장신구(목걸이·반지)는 드랍 가중을 낮게 두고 전용 소리를 준다. 떨어지는 순간의 맑은 금속음 하나로 "장신구다"를 알 수 있어야 한다. 등급이 높으면 그 위에 등급 소리가 겹친다.
- 슬롯이 늘면 한 판에서 떨어져야 할 장비 수도 늘어난다. 드랍 빈도는 시뮬레이션으로 다시 맞춘다.

### 5.2 등급의 문법

| 등급 | 구성 | 역할 |
|---|---|---|
| 일반 | 기본 능력치만 | 초반 채우기, 해체 재료 |
| 마법 | 접두 1 또는 접미 1, 최대 각 1 | 방향 잡기 |
| 희귀 | 접두·접미 합 3~4 | 주력. 굴림 편차가 파밍 동기 |
| 전설 | 무작위 접사 2~3 + 고정 전설 효과 1 | 빌드를 바꾼다(스킬 행동 변화) |
| 유니크 | 고정 이름·고정 효과, 수치만 굴림 | 수집 대상. 분기 하나를 정의한다 |

**시작 수량**: 전설 효과 3종 + 유니크 3종(지금 있는 것)으로 문법을 먼저 검증한다. 검증 뒤 제1장 목표인 전설 12종·유니크 9종으로 늘린다. 세트는 후속.

### 5.3 아이템 레벨과 요구 레벨

- 아이템 레벨은 떨어뜨린 적의 던전·구역 레벨을 따른다. 정예 +2, 우두머리 +3.
- 접사는 아이템 레벨로 해금되고 상위 단계가 열린다.
- 요구 레벨은 영구 캐릭터 레벨을 기준으로 한다. **영구 레벨이 생기기 전(L1 단계)에는 판 안 레벨을 임시 기준으로 쓰고, G1에서 기준을 한 번 바꾼다.**

### 5.4 보물 등급표

디아2 표의 구조(뽑기 횟수, 미드랍 가중, 등급 보정, 하위 표 중첩, 첫 처치 전용 표)를 따른다. 이름·수치·아이템은 복제하지 않는다.

| 표 | 뽑기 | 등급 경향 | 비고 |
|---|---|---|---|
| 일반 적 | 1회, 대부분 미드랍 | 일반·마법 위주 | 영혼·회복약 포함 |
| 정예 | 2회 | 마법 이상 확정, 희귀 가능 | |
| 보물 운반자 | 3회 | 희귀 위주, 장신구 가중 높음 | 도망치는 사건형 적 |
| 구역 우두머리 | 4회 | 희귀 확정 1, 전설 가능 | |
| 던전 보스 | 6회 | 희귀 다수, 전설·유니크 가능 | 유니크는 전체 풀에서 추첨 |
| 던전 보스 첫 처치 | 위 + 확정 1 | 주력 분기 유니크 확정 | 주인공별 1회 |

한 판의 체감 목표(가설): 희귀 3~5개, 장신구 1개 안팎, 전설은 세 판에 한 번꼴, 새 유니크는 다섯 판에 한 번꼴. 원하는 파밍 길이에 맞춰 드랍 시뮬레이션으로 조정한다.

### 5.5 주웠을 때

- 판 중에는 걸어가면 줍는다. 전투는 멈추지 않는다.
- **더 좋은 장비일 때만 알린다.** 착용 중인 것보다 낫다고 판정되면 화면 가장자리에 작은 알림(이름, 등급, 오른 능력치 한 줄, 단축키)이 뜬다. 키 하나로 바로 착용하거나 무시한다. 전투는 멈추지 않는다.
- "더 좋다"의 판정: 같은 슬롯에서 주력 계열에 맞는 점수가 높거나, 등급이 전설 이상이거나, 빈 슬롯일 때. 전설·유니크는 점수와 무관하게 항상 알린다(효과가 달라서 점수로 비교할 수 없다).
- 자세한 비교는 구역 관문, 마을, 결과 화면에서 한다.

### 5.6 얻는 순간의 연출

- 등급별 빛기둥의 색과 높이, 떨어지는 소리, 미니맵 표시.
- 장신구 전용 소리(5.1).
- 전설·유니크는 떨어지는 순간 짧은 화면 반응과 고정 이름표.
- 우두머리가 죽으면 전리품이 한꺼번에 솟아올라 흩어진다.
- 결과 화면에 이번 판 전리품 요약, 처음 얻은 유니크 표시. 유니크 도감.

### 5.7 뒤로 미루는 것

소켓·룬·보석, 세트, 감정, 제작 레시피, 상인·도박.

### 5.8 서사와의 연결(결정 필요)

인간성을 수치 시스템으로 만들지는 정하지 않았다. 두 안이 있다.
- **이야기만**: 인간성은 대사와 장 전개로만 다룬다. 시스템 부담이 없다. 제1장은 이 안으로 시작할 것을 권한다.
- **시스템화**: 대가가 붙은 강한 은총을 고를수록 인간성이 깎이고, 마을의 반응·결말·일부 장비 착용 조건이 달라진다. 재미의 여지가 크지만 밸런스와 분기 서사가 함께 늘어난다. 2막부터 검토한다.

## 7. 에셋 제작 경로

| 대상 | 방법 | 상태 |
|---|---|---|
| 여악마 3명 일러스트(은총 화면, 컷인, 제단) | 이미지 생성. 프롬프트는 `ART-PROMPTS.ko.md` | 프롬프트 제공. 생성은 사용자가 ChatGPT에서 하거나, 승인 시 API 스크립트로 |
| 주인공 3명 일러스트(선택 화면, 초상) | 같은 방법 | 프롬프트 제공 |
| 주인공 3D 모델 | Sunra의 3D 생성 또는 Blender MCP | **검증 과제**. 아래 참조 |
| 트리 노드·장비 아이콘 | 이미지 생성 후 정리 | 미착수 |
| 주문·필살기 이펙트 재료 | 셰이더 + 생성 플립북 | M2에서 냉기부터 |
| 타이틀·인트로 PV 영상 | 영상 생성 | **후속 과제로 남김** |

**3D 모델 검증 과제**: 이미지에서 3D를 만드는 도구는 대개 정지 메시를 준다. 게임에 쓰려면 리깅과 애니메이션(대기·이동·시전·피격·회피·사망)이 붙어야 하고, 지금 게임의 주인공 표현 코드는 기존 마법사 모델의 뼈대 이름에 맞춰져 있다. 주인공 한 명으로 "일러스트 → 3D 메시 → 리깅 → 기존 애니메이션 이식 → 게임 안 표시"가 끝까지 되는지 먼저 확인한다. 이 세션에는 Blender MCP가 연결돼 있지 않다. Sunra는 비용 조회와 승인 뒤에 쓴다.

**차선책**: 3D 경로가 막히면 주인공 세 명은 기존 마법사 모델의 색·실루엣 변형으로 구분하고, 캐릭터의 매력은 2D 일러스트가 맡는다.

**일러스트 수위**: 성인 캐릭터의 매력을 살리되 노출 수위의 기준은 배포 플랫폼의 등급 규정에 맞춰 정한다. 프롬프트는 노출이 과하지 않은 기준으로 썼다.

## 8. 구현 순서

코어를 바꾸는 단계마다 골든 리플레이 해시가 바뀐다. 의도한 변경임을 기록하고 갱신한다.

| 단계 | 내용 | 종료 조건 |
|---|---|---|
| M1-A | 코어 평탄화(포크 정리) | 골든 일치 |
| M2 | 냉기 90초: 손맛 + 긴장 + 주력 밀도 | 사용자 비교 평가 |
| L1 장비 문법 | 8슬롯, 등급 5단계, 접두·접미, 아이템 레벨, 보물 등급표, 전설 3종. 요구 레벨은 판 안 레벨 기준. 드랍 시뮬레이션 도구 | 시뮬레이션의 등급·장신구 분포가 목표 범위, 기존 저장 보존 |
| G1 성장 분리 | 서리의 마녀: 영구 경험치·레벨·포인트·트리, 은총 카드 전환, 요구 레벨 기준 전환 | 재실행 유지, 중복 지급 없음, 수동 완주 1회 |
| H1 마을 0판 | 한 화면 허브: 제단(트리), 보관함, 대장장이("재" 재굴림), 던전 입구, 인물 대사 | 마을 → 던전 → 귀환이 끊기지 않음 |
| L2 득템 연출 | 5.5·5.6 전부, 장신구 소리, 우두머리 전리품 분출 | 사용자 플레이에서 득템의 순간을 지목할 수 있음 |

| M6 | 제1장 완주 후보 | 사용자 완주, 성능, 저장 |
